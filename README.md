# healthcare-data-analysis-project
This project is a complete end-to-end SQL project using a real healthcare dataset from Kaggle


The 5 questions your project will answer
How do admissions change month by month? Is there a seasonal pattern?
Who is most at risk of dying in hospital? Compare death rate (OUTCOME = 'EXPIRY') by age group and gender.
Emergency vs outpatient: do emergency admissions stay longer or die more often?
Which conditions are most common, and which are most deadly?
Does bad air matter? On high AQI days, are there more admissions or more people brought in dead?
